# docs/postmortem/ · 事故复盘

> 本目录记录真实事故——当前为空，出现事故后按模板填写；复盘纪律见 `OWNERS.md` 的「事故处理」。

## 模板

```markdown
# Postmortem: <事故标题>

- **日期**：YYYY-MM-DD
- **影响面**：……
- **状态**：open / resolved

## 时间线

<!-- 按时间顺序记录事实 -->

## 根因

<!-- 为什么会发生；现有防线为何没拦住 -->

## 修复项

<!-- 逐项列出修复动作 -->

## 验证

<!-- 如何确认修复有效 -->
```
