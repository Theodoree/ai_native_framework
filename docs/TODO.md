## 平台能力

| 事项                         | 现状                                                                                    | 开工前要先定的事                                                   |
| ---------------------------- | --------------------------------------------------------------------------------------- | ------------------------------------------------------------------ |
| 节点级 `harness` / `version` | 后端与前端正在做（`GET /api/templates`、链条编辑器下拉框），落地后删掉本行              | —                                                                  |
| 自定义 AGENTS.md 落文件      | 正在做：库里存路径与 md5、正文落 `$HOME/.<项目名>/agents/`，md5 不符拒跑                | —                                                                  |

| 审计日志                     | 只有业务事件（`events` 表），没有「谁登录了 / 谁改了权限」                              | 记到什么粒度、留存多久、能不能被管理员删                           |
| 会话                         | 7 天固定有效期，不滑动续期；没有自助找回密码                                            | 是否续期、是否要邮箱或管理员重置以外的路径、要不要双因素           |
| 观测                         | 只有 stdout 日志，无 metrics、无健康详情端点                                            | 用哪套（Prometheus 抓哪个端点 / 只留 `/api/bootstrap`）            |
| 图片                         | 上限 5 张 / 5MB，按文件头认类型；不扫描、不缩略                                         | 要不要病毒扫描、要不要对象存储                                     |
| 链条形态                     | 只有线性六站（`create → assess → dev → crosstest → merge → release`），无分支、无并行站 | 真要分支时，需求要能停在两处，状态机与 UI 都得改                   |
