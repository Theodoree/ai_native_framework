# P-07 门牌幂等重算

- **日期**：2026-10-20
- **状态**：proposed
- **里程碑**：M2 · 门与门牌
- **依赖**：P-03

## 背景

`docs/last-change.md` 规定门牌是派生数据、由 CI 幂等重算、取后合并者。现在没有任何 job 在做这件事，而 merge gate 的第 4 条守卫依赖门牌含本 PR 编号。

## 目标 · 验收 · 边界

- **目标**：PR 的 LAST-CHANGE 表始终是重算结果，同一份输入重算两次得到同一答案。
- **验收**：同一条 PR 触发两次重算，两次表格内容逐字相同（`git diff` 为空）；合并后合并人/合并日期被补写；两次 PR 改同一模块时按「后合并者」得到结果，不产生人工冲突。
- **边界**：可动 `.github/workflows/`（新增 job）、`scripts/`（新增重算脚本）、`tests/`。不动 PR 模板。

## 放弃了什么

- **手写门牌清单**：门牌、issue 状态、PR 描述三处各记一份，必然有一处过期。
